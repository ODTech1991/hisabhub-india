# HisabHub 🇮🇳

**India's Smart Finance & Tax Toolkit**

HisabHub is a modern, privacy-first toolkit for Indian accountants, GST practitioners, tax consultants, businesses, finance professionals, students and individuals.

## Included in this starter

- GST Calculator
- GST Inclusive / Exclusive Calculator
- GSTIN Checker UI foundation
- Reverse Charge Calculator UI foundation
- SIP Calculator
- Loan EMI Calculator
- FD / RD module placeholders
- Profit Margin Calculator
- Discount / Percentage module placeholders
- TDS module placeholder
- Global tool search
- Category filtering
- Dark mode
- Responsive dashboard
- Browser-only calculation architecture
- Unit-tested calculation engine
- GitHub Pages-ready Vite configuration

## Tech Stack

React + TypeScript + Vite + Lucide React.

## Run locally

```bash
npm install
npm run dev
```

## Test

```bash
npm test
```

## Build

```bash
npm run build
```

## GitHub Pages

The Vite base is configured for relative assets. Build the project and publish the `dist` directory through GitHub Pages.

## Important

GST rates, tax provisions, thresholds and statutory rules can change. This application is intended for general informational and calculation purposes. Verify current provisions from official sources before making tax or financial decisions.

The GSTIN checker must never claim active registration status unless an authoritative GST data source has actually been queried.

## Roadmap

Future modules can include GSTR-1, GSTR-3B, GSTR-9 reconciliation, ITC tools, HSN/SAC lookup, GST interest and late-fee calculators, TDS/TCS tools, BRS, invoicing, payroll, depreciation and working-capital tools.
